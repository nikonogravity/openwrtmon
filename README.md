# OpenWRT Monitor (Go Edition) 🛡️

Компактная системная утилита в трее для **Windows, macOS и Linux**.
Позволяет в один клик переключать VPN (AmneziaWG) и WAN на роутере с OpenWRT, в реальном времени отображает **внешний IP, флаг страны подключения и статус туннеля**.

---

## ✨ Возможности

- 🚀 **Полная автономность:** написана на Go, скомпилирована в один компактный файл (~7.7 МБ). **Никаких Python, Node.js или веб-серверов!**
- 🇳🇱 **Крупный флаг страны в трее:** автоматически определяет страну выхода, скачивает официальный флаг и динамически рисует его прямо в панели задач.
- 🔍 **Автоопределение интерфейса AmneziaWG:** автоматически находит интерфейс по протоколу `amneziawg`, даже если вы переименовали его в `awg0`, `vpn`, `amnezia` или любое другое имя.
- ⚡ **Управление в 1 клик по значку в трее:**
  - 🟢 / 🔴 Статус подключения и реальное имя туннеля
  - ⛔ / 🛡️ **Единая кнопка-переключатель:** показывает *«Отключить AWG»*, если туннель поднят, или *«Включить AWG»*, если опущен
  - 🔄 Перезапустить AWG
  - 🌐 Перезапустить WAN (сброс сессии провайдера)
  - 🖥️ Быстрый переход в веб-интерфейс LuCI
  - 🔃 Принудительное обновление статуса
- 📊 **Индикация статуса:**
  - 🟢 Зелёная точка = VPN активен
  - 🔴 Красная точка = Прямое подключение (VPN выключен)
  - 🟠 Оранжевая точка = Идёт переключение
  - ⚫ Серая точка = Роутер недоступен / ошибка

## 💻 Установка на Windows

### Запуск:
Двойной клик на **`openwrtmon.exe`** — программа мгновенно появится в трее рядом с часами.

### Установка в автозагрузку (1 клик):
Запустите скрипт **`install.ps1`** (правый клик → *Выполнить с помощью PowerShell*):
- Скопирует файл в `AppData\Local\Programs\OpenWRTMonitor`
- Создаст ярлык на Рабочем столе
- Добавит программу в Автозагрузку Windows

---

## 🍏 Установка на macOS / 🐧 Linux

```bash
chmod +x install.sh
./install.sh
```
Скрипт скопирует бинарник в `~/.local/bin/openwrtmon` и настроит автозапуск через **LaunchAgent** (macOS) или **systemd --user** (Linux).

---

## ⚙️ Настройка (`config.ini`)

Файл `config.ini` создаётся рядом с программой:

```ini
[router]
url = http://192.168.1.1
username = root
password =        ; оставьте пустым, если пароля нет

[interfaces]
awg = awg         ; или оставьте пустым для автоопределения по proto "amneziawg"
wan = wan

[settings]
poll_interval = 5 ; секунд между проверками
```
